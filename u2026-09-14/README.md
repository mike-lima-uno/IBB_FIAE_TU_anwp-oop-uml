# Alcohol Concentration Test

This project estimates blood alcohol concentration using the Widmark formula.

The application creates two people, Hansel and Gretel, who drink the same
amount of alcohol. Because they have different body masses and distribution
factors, their estimated alcohol concentrations are different.
